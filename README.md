## 📖 Overview

SignBridge is an innovative accessibility project designed to make communication more inclusive. The platform aims to translate sign language gestures into text and speech, enabling seamless interaction between sign language users and the broader community.

Our mission is to leverage modern web technologies and computer vision to create a practical, affordable, and accessible communication solution.

---

## 🚨 Problem Statement

Millions of deaf and hard-of-hearing individuals rely on sign language for daily communication.

Unfortunately, many people are not familiar with sign language, creating barriers in:

* Education
* Healthcare
* Workplaces
* Public Services
* Everyday Conversations

This communication gap often leads to misunderstanding, exclusion, and limited accessibility.

---

## 💡 Solution

SignBridge provides a technology-driven communication bridge by converting sign language gestures into understandable text and speech.

The system is designed to:

* Recognize hand gestures
* Interpret sign language
* Convert signs into readable text
* Generate speech output
* Improve accessibility and inclusion

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/atharvranmale/SignBridge.git
```

### Navigate to Project Directory

```bash
cd SignBridge
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```
